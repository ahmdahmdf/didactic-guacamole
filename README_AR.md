# مشروع تطبيق كتاب التوحيد

هذا مشروع Flutter أولي لتطبيق أندرويد عربي لقراءة ملف PDF المرفق دون إنترنت.

## ما الذي يعمل في هذه النسخة؟
- تضمين ملف PDF داخل التطبيق ليعمل دون اتصال.
- واجهة عربية من اليمين إلى اليسار.
- فتح الكتاب والانتقال بين الصفحات.
- حفظ آخر صفحة تمت قراءتها.
- إضافة صفحات إلى المفضلة وإزالتها.
- الوضع الليلي والنهاري.

## ما الذي لم يكتمل بعد؟
- البحث داخل نص الكتاب والفهرس التفصيلي: ملف PDF المرفق صفحات مصوّرة، لذلك يلزم OCR لاستخراج النص ثم مراجعته يدوياً.
- تكبير الخط المستقل: محتوى PDF يحتفظ بتكبيره عبر إيماءة اللمس.
- اختبار البناء على أجهزة أندرويد فعلية وإعداد بيانات Google Play.

## المتطلبات
- Flutter SDK حديث.
- Android Studio أو Android SDK.
- اتصال إنترنت أول مرة لتنزيل حزم Flutter فقط.

## إنشاء ملفات أندرويد
1. فك ضغط المشروع.
2. افتح الطرفية داخل مجلد `kitab_at_tawheed_app`.
3. نفّذ:
   ```bash
   flutter create --platforms=android .
   ```
4. ثم:
   ```bash
   flutter pub get
   flutter run
   ```

## إنشاء ملف النشر AAB
بعد اختبار التطبيق وإكمال بيانات الحزمة والتوقيع:
```bash
flutter build appbundle --release
```
سيكون الملف عادة في:
`build/app/outputs/bundle/release/app-release.aab`

## تنبيهات مهمة قبل النشر
- تحقق من امتلاك إذن توزيع هذه الطبعة من الكتاب؛ رفع ملف PDF لا يمنح تلقائياً حق إعادة نشره.
- أضف سياسة خصوصية دقيقة إذا أضيفت لاحقاً ميزات تجمع بيانات أو تستخدم خدمات خارجية.
- أكمل متطلبات الاختبار والتحقق الخاصة بحساب Google Play Console.
- لا ترفع التطبيق قبل اختباره على جهاز حقيقي والتأكد من سلامة عرض كل الصفحات.
